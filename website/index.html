Core Capabilities

Engineered for Reliability & Data Safety

No cloud lock-in, no lossy compression, and no accidental deletion. Built on high-performance .NET 10.

📥

Lossless iPhone USB Archiving

Direct Apple File Conduit (AFC) protocol over USB. Eliminates Windows MTP explorer crashes and 0-byte corrupt transfers. Live Photos, RAW, and AAE sidecars paired seamlessly.

🛡️

Strictly Read-Only iPhone Safety

Hardened by architecture and compile-time Mono.Cecil contract tests. PicHarbor only ever reads from /DCIM/ and cannot write, modify, or delete anything on your device.

🔍

Offline SQLite Index & Search

Browse archives and search media instantly without reconnecting devices. Query by date, camera model, media type, file size, or GPS coordinates with gallery lightbox preview.

🍏

Restore & Sync to iPhone

Generates structured sync albums (flat or YYYY-MM) for Apple Devices or iTunes to synchronize back into iOS Photos, keeping Live Photo video/photo links completely intact.

🤖

Restore & Incremental Android Sync

Direct FTP synchronization to Android or Pixel devices. Supports full restore or incremental skip based on SQLite historical records to avoid repeated transfers.

☁️

Google Photos Cloud Backup

Integrated gpmc cloud bridge with automatic OAuth token capture, Pixel unlimited storage or Storage Saver quality, auto-albums, and retry with jitter backoff.

Dual Interfaces

Choose the Way You Work

True Native AFC Archiving

Bypasses flaky Windows MTP. Employs SQLite journaling and atomic writes (.partial → size verification → atomic rename). Transfers cleanly resume after disconnects.

  • Direct AFC protocol via usbmuxd service
  • Flexible scope: full roll, date range, or DCIM folder
  • Automatic organization: month, year-month, year, or flat

Safety by Design

Zero Risk of Data Loss

Your original photos on iPhone are strictly read-only. Every write on PC is atomic and journaled.

🛡️

Architectural Read-Only Contract

Enforced at build time via Mono.Cecil byte-scanning unit tests. The core engine does not import or call any device-write API.

⚡

Atomic Write Pipeline

Transfers write to .partial temporary files, verify byte lengths, and rename atomically. Interrupted files never leave corrupt zero-byte artifacts.

⏱️

Forward-Progress Watchdog

Detects stalled connections and graceful disconnect timeouts. Unplugging mid-copy safely exits and seamlessly resumes on reconnect.
