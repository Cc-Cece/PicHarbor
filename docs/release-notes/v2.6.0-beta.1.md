# Release notes — v2.6.0-beta.1

**Release date:** 2026-11-01
**Tag:** `v2.6.0-beta.1`
**Channel:** prerelease. This build does not replace the stable desktop release v2.5.9.

## 中文

这是测试版，不替换当前正式版 v2.5.9。

Windows 上传到 Google 相册时，成对实况照片可以按三种方式处理。默认是「原始照片配对」：静止照片和视频仍是手机上的原始字节，云端显示为一个可播放的项目。另外两种是「动态照片封装」和「原始照片配对（分步上传）」。这个选择只影响之后新上传的成对文件，已经在云端的不会重传。本身已是一个动态照片文件的，仍按原文件上传。画质选项不变。

电脑可以在同一个 Wi-Fi 下接收 iPhone 或 Android 发来的照片，不需要数据线或 FTP。iPhone 的数据线备份和 Android 的 FTP 备份都还在。电脑显示名称、两分钟有效的六位配对码和二维码。配对后两边记住长期密钥，之后不再输入配对码。实况照片以两个原始文件写入归档，传输时不封装。iPhone 发送时必须保持 PicHarbor 在前台，锁屏后传输会停止。Android 可以在屏幕关闭后继续已经开始的发送。

## Highlights

- Google Photos on Windows can upload a two-part Live Photo as one cloud item. The default keeps both original files and links them. Motion-photo packaging and a two-step attach are optional. The choice applies only to new uploads.
- A single file that is already a motion photo is uploaded unchanged.
- The computer can receive photos from PicHarbor on iPhone or Android over the same Wi-Fi. USB backup and Android FTP backup stay available.
- Received Live Photos stay two original files in the archive. They are not muxed during the transfer.

## Limits

- This is a beta. Install it beside v2.5.9 if you still want the stable build. GitHub marks this tag as a prerelease and does not set it as latest.
- The phone must be on the same LAN. There is no internet relay, VPN, or guest-network support.
- Sending is phone to computer only.
- iPhone must keep PicHarbor in the foreground. Locking the screen stops the transfer, because a background session cannot check this computer's self-signed certificate. The next batch also needs PicHarbor open. Android can keep sending after the screen turns off.
- Motion-photo packaging on Windows does not read the still-image time. Playback starts at the beginning of the video. The log says so.
- The Windows firewall may ask to allow PicHarbor.Gui.exe the first time the receiver starts.

## Upgrading

Replace `PicHarbor.Gui.exe` only if you want this beta. The first Google Photos connection still uses the bundled Python runtime under `%LocalAppData%\PicHarbor\runtime\`. Paired phones and the receiver certificate are stored under `%LocalAppData%\PicHarbor\link\`.
