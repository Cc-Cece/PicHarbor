# Release notes — v1.0.1

**Release date:** 2026-06-21
**Tag:** `v1.0.1`

A **security patch** release. There are **no functional or behavioral changes** from v1.0.0 — same
read-only copier, same CLI and options, same on-disk format. This release simply rebuilds the single-file
EXE against a **patched SQLite**.

## What changed

- **Security:** bumped the bundled native SQLite — `SQLitePCLRaw.bundle_e_sqlite3` `3.0.3`, which carries
  SQLite **3.50.3** — to remediate **CVE-2025-6965** (GHSA-2m69-gcr7-jv3q, **HIGH**): an aggregate-terms
  memory-corruption issue in SQLite versions before 3.50.2.
  - **Real-world exposure was minimal:** `get-and-see` uses SQLite only for its own local journal database
    that it creates and controls — it never runs untrusted SQL, never opens untrusted database files, and
    makes no network access. The patched library ships regardless, and the build now fails on any known
    package vulnerability (`NuGetAudit` + warnings-as-errors).

## Upgrading

A drop-in replacement for v1.0.0. Download `get-and-see.exe`, verify the published SHA-256, and use it
exactly as before. Existing archives and journals are fully compatible — no re-copy or migration needed.

Everything from [v1.0.0](v1.0.0.md) still applies.
