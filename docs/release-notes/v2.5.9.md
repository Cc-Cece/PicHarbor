# Release notes — v2.5.9

**Release date:** 2026-10-31
**Tag:** `v2.5.9`

## 中文

Google 相册的登录和上传不再调用电脑上安装的 Python。安装包内置 CPython 3.12.10，以及同步引擎需要的依赖。设置里的“Python 解释器路径”已移除。没有安装 Python，或没有安装 `requests` 的电脑，完成 Google 登录后也可以继续换取账号。

## Highlights

Google Photos sign-in and upload no longer use the Python installation on the computer. PicHarbor ships a private CPython 3.12.10 runtime, with the packages the sync engine imports, and always starts that `python.exe`.

## Fixes

- After a Google sign-in, machines without `requests` and `rich` installed could keep showing “未登录 / 未设置凭据” even though the `oauth_token` cookie had been saved. The account exchange runs inside the bundled runtime, so a missing system Python no longer stops it.
- The Settings card for a Python interpreter path is removed. An old `GooglePhotosPythonPath` value in `config.json` is ignored.

## Upgrading

Replace `PicHarbor.Gui.exe`. The first Google Photos connection extracts the runtime to `%LocalAppData%\PicHarbor\runtime\python\`. No Python install and no PATH change is required.
